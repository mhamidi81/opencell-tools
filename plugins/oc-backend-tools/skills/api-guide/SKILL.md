# API Development Guidelines

Before making any API layer changes, read and follow the guidelines in these files:

1. **API patterns**: Read `${CLAUDE_PLUGIN_ROOT}/guidelines/API_GUIDELINES.md` for REST endpoints, DTOs, API services, mapper methods, documentation
2. **Code quality**: Read `${CLAUDE_PLUGIN_ROOT}/guidelines/CODE_QUALITY.md` for exception handling, resource management, formatting
3. **Critical rules**: Read `${CLAUDE_PLUGIN_ROOT}/guidelines/CRITICAL_RULES.md` for rules that apply to all code

Apply these guidelines when generating or modifying API, REST, or DTO code.
